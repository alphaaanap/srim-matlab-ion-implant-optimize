# srim-matlab-ion-implant-optimize
大创项目：基于srim与matlab实现离子注入工艺参数优化
# 离子注入多能量优化系统（SRIM + MATLAB GUI）
## 项目概述
大创项目：基于 SRIM 离子注入仿真数据，使用 MATLAB 搭建图形化优化平台，构建连续预测模型，自动寻优**离子能量、注入剂量、作用深度**最优工艺参数，支持多种目标浓度分布，输出标准化工艺配方，减少线下实验，降低离子注入工艺成本。
## 技术组成
SRIM 离子仿真 + MATLAB 数据建模 + GUI 交互界面，集成数据导入、校验、建模、参数寻优、结果可视化、配方导出全流程功能。
## 主要功能
批量导入并解析 SRIM 仿真 `.txt` 数据，可视化离子深度-浓度分布
构建连续插值模型，实现任意能量下离子分布预测
自定义盒状/斜坡类目标注入剖面，实时预览
自动优化 1~3 组离子能量与剂量组合，计算拟合误差
SRIM 结果二次验证，一键导出可落地的工艺配方文档
## 使用方式
1. MATLAB 环境运行主程序，启动 GUI 界面
2. 导入本地 SRIM 仿真数据，完成建模与参数配置
3. 一键执行自动优化，查看并导出最终工艺方案
